How to Run

Synth only

chuck gm.ck
python gm_gui.py

Drums only

chuck drum.ck
python gm_gui.py

Both together (synth + drums, timed)

chuck gm.ck drum.ck
python gm_gui.py

When both files are loaded into the same ChucK VM they share the same audio clock and both route to dac, so they mix automatically in perfect sample-accurate sync. The GUI sends OSC to port 9000 (synth) and port 9001 (drums) independently. Use the STEP SEQUENCER BPM and the DRUM MACHINE BPM to control each independently, or type the same value in both for locked sync.

The two ChucK files do not share state — you can stop/start either sequencer without affecting the other.

Drum Parameters Explained

KICK

KnobRangeWhat it does
DECAY ms20 – 800 ms How long the kick's amplitude rings out. Short (60 ms) = tight electronic click. Long (500 ms) = boomy 808 tail.
TUNE Hz30 – 200 Hz The starting frequency of the pitch sweep. Higher = brighter attack transient. Lower = deeper, thudier hit. The pitch then sweeps down to a fixed ~40 Hz endpoint.
P.DEC ms10 – 200 ms Pitch Decay — how quickly the pitch falls from TUNE Hz to the end frequency. Short = snappy TR-808 style. Long = drawn-out "boing" / tom-like.
DRIVE0 – 100 Input gain before the hard limiter. Higher values push the sine wave into saturation/clipping, adding harmonics and grit. At 0 the kick is clean and subby; at 100 it crunches.
LFO Hz0.05 – 20 Hz Speed of the pitch LFO. At slow rates (0.3 Hz) each hit sounds slightly different over time — organic, tape-like. At fast rates (8+ Hz) you get rapid pitch wobble every hit.
LFO AMT0 – 80 Hz How much the LFO shifts the starting pitch away from TUNE Hz on each hit. 0 = no modulation (all hits identical). 20–40 = subtle humanisation. 80 = wild pitch variation.

SNARE

KnobRangeWhat it does
DECAY ms20 – 500 ms Amplitude decay of both the tone and noise layers. Short = crisp rimshot. Long = open, washy snare.
TUNE Hz80 – 500 Hz Center frequency of the sine body tone. Low (100 Hz) = fat, thumpy snare. High (400 Hz) = thin, snappy rimshot character.
SNAP0 – 100 Balance between the noise layer and the tone layer. 0 = pure sine body (tom-like). 100 = mostly bandpass noise (pure snare buzz). Around 60–75 gives a natural snare blend.
LFO Hz0.05 – 20 Hz LFO rate for tone pitch modulation.
LFO AMT0 – 120 Hz How much the LFO displaces the body tone frequency on each hit. Useful for pitch-bent snare flams or detuned cross-stick sounds.

HI-HAT (closed) & HI-HAT (open)

KnobRangeWhat it does
C.DEC ms10 – 200 ms Closed hi-hat decay. Short (15–40 ms) = tight, clicking closed hat. Longer = more like a rim tap.
O.DEC ms50 – 800 ms Open hi-hat decay. Longer values (200–600 ms) create the classic sizzling open hat sustain.
LFO Hz0.05 – 20 Hz LFO rate for HPF cutoff modulation.
LFO AMT0 – 4000 Hz How much the LFO shifts the high-pass filter cutoff on each hit. Even small amounts (200–500 Hz) add shimmer and tonal variety between hits. Large values drastically change the hi-hat character.

DRUM VOL — MASTER

KnobRangeWhat it does
MASTER0.0 – 1.0 Overall drum output level fed into the master Dyno limiter. The limiter catches any summing peaks — so you can push this fairly hard without hard clipping at the DAC.

Drum Signal Flow

KICK SinOsc → [LFO samples pitch start per hit] → ADSR(amp) + Noise → ADSR(click) → Gain(drive) → Dyno(lim 0.85) ──────────────────────────┐ SNARE SinOsc → [LFO offsets tone.freq per hit] → ADSR(tone) Noise → BPF(3.5kHz) → ADSR(noise) → Gain(mix) → Dyno(lim 0.85) ───────────────────────────┤ HIHAT Noise → [LFO offsets HPF cutoff per hit] → HPF(~7.8kHz) → ADSR(closed or open decay) → Dyno(lim 0.85) ────────────────────────────────────────┤ ↓ Gain(master) → Dyno(masterLim 0.92) → dac
Each voice has its own hard limiter at 0.85. The master limiter at 0.92 catches summing peaks when multiple voices hit simultaneously (worst case: 3 × 0.85 × 0.55 = 1.4 — the master limiter brings this back down cleanly).

GrandMotherMoog (gm.ck) Parameters

VCO 1 / VCO 2

ControlRangeWhat it does
WAVEOFF / TRI / SAW / SQROscillator waveform. SAW = bright, harmonically rich. SQR = hollow, reedy. TRI = mellow, flute-like.
LEVEL0.0 – 1.0Oscillator output level into the mixer.
DETUNE c−50 – +50 centsVCO2 pitch offset relative to VCO1. Small values (5–15 cents) add chorus/width. Large values (±50) create parallel interval effects.

MIXER

ControlRangeWhat it does
NOISE0.0 – 1.0White noise level. Low (0.01–0.05) adds analog texture. High (0.5+) creates wind/breath sounds.
EXT IN0.0 – 1.0Level of audio patched into the synth's inlet (Chugraph inlet). Can be used to filter external signals.

FILTER (4-pole Moog-style cascade)

ControlRangeWhat it does
CUTOFF0 – 100Base low-pass filter cutoff. Maps exponentially: 0 ≈ 40 Hz (nearly closed), 100 ≈ 8000 Hz (wide open). Stack with ENV AMT for the classic synth filter sweep.
RES0 – 100Resonance (Q) per filter stage. 4 stages cascade, so even moderate values produce a strong peak. High values (70+) self-oscillate.
ENV AMT0 – 100How much the filter envelope opens the cutoff. 0 = cutoff stays at base. 100 = filter env adds up to 6000 Hz above the base cutoff.

LFO

ControlRangeWhat it does
RATE Hz0.05 – 20 HzLFO speed. Below ~5 Hz = classic slow modulation. Above 10 Hz = audio-rate FM territory.
→PITCH0 – 100LFO depth applied as additive Hz offset to both VCOs. Creates vibrato.
→CUTOFF0 – 100LFO depth applied to filter cutoff. Creates wah / auto-filter sweeps.

AMP ENV / FILT ENV (ADSR)

ControlRangeWhat it does
A ms1 – 2000 msAttack time — how long until full amplitude/cutoff is reached.
D ms1 – 2000 msDecay time — how long to fall from peak to sustain level.
S0.0 – 1.0Sustain level — amplitude/cutoff held while key is gated on.
R ms1 – 2000 msRelease time — how long to fade to silence after note off.

FX

ControlRangeWhat it does
DRIVE0 – 100Pre-limiter gain. Pushes the signal into the hard limiter for saturation/crunch. 0 = 0.8× gain (clean). 100 = 6× gain (heavy distortion).
REVERB0 – 100NRev wet/dry mix. 0 = dry. Maps to 0–25% wet.

GLIDE

ControlRangeWhat it does
ms0 – 500 msPortamento time. 0 = no glide (instant pitch change). Higher values create legato pitch slides between notes.

GrandMotherMoog Signal Flow

VCO 1 (TRI / SAW / SQR) ─┐ VCO 2 (TRI / SAW / SQR) ─┤ ← LFO → pitch (vibrato) NOISE ─┤ EXT IN ─┘ ↓ Gain(mix) ↓ Gain(drive) ← DRIVE knob ↓ LPF → LPF → LPF → LPF (4-pole cascade) ← cutoff = base + filtEnv×amt + LFO×lfoCutoff ↓ ADSR(ampEnv) ↓ Gain(velGain) ← velocity 1–127 ↓ Dyno(limiter ∞:1) ↓ NRev(reverb) ↓ dac (output) FILT ENV (ADSR) ────────────────→ filter cutoff offset LFO ────────────────→ pitch & cutoff

LFO Modulation in the Drum Machine

Each drum voice has a free-running SinOsc lfo that is sampled once at the moment of each hit. This means the LFO doesn't continuously move the pitch — instead, every time a drum step fires, it takes a snapshot of the LFO's current value and uses that as a one-time offset for that hit.

The result is that consecutive hits sound slightly different from each other, creating an organic, humanised feel rather than robotic repetition. The rate of change between hits depends on both the LFO speed and the BPM.

VoiceWhat the LFO modulatesEffect
KICKPitch sweep start frequency (freqStart ± LFO AMT)Each kick has a slightly different pitch attack — some tighter, some deeper
SNAREBody tone center frequency (TUNE ± LFO AMT)Snare body tonal pitch drifts, creating detuned or pitch-bent snare variation
HIHATHigh-pass filter cutoff (HPF ± LFO AMT)Tonal character of each hat changes — some brighter, some darker
Recipe — humanised drum loop: Set all three LFO AMT values to ~10–20% of their ranges with slow LFO rates (0.1–0.5 Hz). The sequencer will never repeat the exact same pattern twice, even with a fixed step grid.
Recipe — techno wobble kick: KICK LFO Hz = 1.5 Hz, LFO AMT = 50 Hz. Combined with a long pitch decay (P.DEC = 80 ms), this creates a kick whose pitch "wobbles" differently with each hit — classic Berlin techno feel.

Tips & Recipes

808-style kick

TUNE Hz   = 60     (very low start)
P.DEC ms  = 120    (slow pitch slide)
DECAY ms  = 600    (long tail)
DRIVE     = 20     (clean)
LFO AMT   = 0      (consistent)

Tight techno kick

TUNE Hz   = 150    (punchy start)
P.DEC ms  = 30     (fast snap)
DECAY ms  = 150    (short)
DRIVE     = 65     (crunchy)
LFO Hz    = 1.0 Hz
LFO AMT   = 25 Hz  (subtle per-hit variation)

Snare with strong crack

DECAY ms  = 80
TUNE Hz   = 300
SNAP      = 85     (mostly noise)

Fat rimshot / electronic tom

DECAY ms  = 120
TUNE Hz   = 120
SNAP      = 20     (mostly tone)
LFO AMT   = 60 Hz  (pitch variation between hits)

Shaker / tambourine (hi-hat channel)

C.DEC ms  = 25
LFO Hz    = 3 Hz
LFO AMT   = 1200 Hz  (varying filter each hit)

Running synth + drums together

# In one terminal:
chuck gm.ck drum.ck

# In another:
python gm_gui.py

Set the STEP SEQUENCER BPM and the DRUM MACHINE BPM to the same value. Both sequences run 16 steps of 1/16th notes — they share the same musical grid automatically since they started at the same moment in the same ChucK VM.

Latency note: The GUI's visual step highlight (the orange strip) runs on Python-side timing which is approximate. Actual audio timing is locked inside ChucK at sample accuracy and will not drift. The visual indicator may drift slightly at very high BPM (>200).
